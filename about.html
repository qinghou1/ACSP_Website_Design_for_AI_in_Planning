About

A shared AI knowledge base for planning

The repository is conceived as a professionally curated platform for accessing and contributing AI-related resources across planning education, research, and practice.

Purpose

Why this repository

To accelerate diffusion of planning AI knowledge and infrastructure, especially for smaller academic programs, public-sector planning offices, graduate students, and the wider planning community.

Discoverable

Browse by Education, Research, and Practice and search through a consistent planning-AI taxonomy.

Curated

Resources are intended to be reviewed for relevance, metadata quality, rights, and publication readiness.

Reusable

Links, context, date/version, and permissions information help audiences assess appropriate reuse.

Prototype scope

What this GitHub Pages version does

Public repository interface

Home, Explore, domain pages, title + description resource lists, search/filter controls, and responsive navigation.

Contribution framework

A structured front-end form aligned with the preliminary metadata and taxonomy, ready to connect to a future submission system.

Portable static architecture

No build process is required. The package can be uploaded directly to a personal GitHub repository and published with GitHub Pages.

Current limitation

Static-hosting boundary

GitHub Pages does not provide a secure database, member authentication, or server-side review queue by itself. The current framework therefore demonstrates the complete public-facing experience and contribution structure while leaving secure submission, member login, and administrative review for later ACSP integration.
